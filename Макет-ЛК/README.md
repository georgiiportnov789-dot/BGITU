# Макет-ЛК — статический прототип личного кабинета (архив)

Это **не рабочая версия**. Рабочий кабинет с базой данных — в `../ЛК-портал/`.

Здесь сохранён исходный статический прототип, по которому делался Django-портал:

- `cabinet.html` — 7 экранов кабинета (обзор, оценки, задолженности, план, заявки, портфолио, почта);
- `assets/` — дизайн-система (tokens, base, components, cabinet), шрифты, скрипты, демо-данные;
- `docs/` — архитектура, скриншоты и архивный концепт редизайна;
- `scripts/serve.py` — локальная раздача статики.

Запуск без Django:

```bash
cd "$HOME/Documents/BGITU/Макет-ЛК"
python3 scripts/serve.py
# открыть http://127.0.0.1:8787/cabinet.html
```
