# БГИТУ-портал — личный кабинет на Django

Рабочий прототип личного кабинета БГИТУ: настоящая база данных, роли и права, курсы, работы студентов, оценки, посещаемость и расписание, импортированное из файла с сайта университета.

- **Стек:** Python 3.11, Django 5.2 LTS, SQLite (по умолчанию), серверные шаблоны + дизайн-система статического макета.
- **Без внешних сервисов:** всё работает локально, никаких API ЭОС и облаков.
- **Данные:** занятия и группы — из файла `bgitu.ru` (1 семестр 2026/27), остальное — демо-данные.

## Запуск

```bash
cd "$HOME/Documents/BGITU/ЛК-портал"
uv venv --python 3.11 .venv && . .venv/bin/activate
uv pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo          # роли, пользователи, курсы, расписание
python manage.py runserver 127.0.0.1:8010
```

Открыть `http://127.0.0.1:8010/` — редирект на вход. Пароль всех демо-аккаунтов: `demo12345`.

## Регистрация

`/register/` — самостоятельное создание кабинета: фамилия и имя, логин, e-mail,
группа (необязательно), пароль. После отправки создаётся `User` + `Profile`,
назначается роль «Студент», выполняется вход и редирект в `/cabinet/`.
Проверяются уникальность логина и e-mail, формат, совпадение паролей и
стандартные валидаторы Django. Другую роль пользователь запрашивает в `/roles/`.

## Расписание

Файл скачан с сайта БГИТУ: [очное обучение, 1 семестр 2026/27, группы ИВТ/ИСТ/ПИ/ПрИ](https://bgitu.ru/studentu/raspisanie/ochnoe-obuchenie/2026-27/1-semestr/v8/) → `fixtures/schedule/bgitu-2026-27-1semestr-IVT-IST-PI-PRI.xls` (81 КБ, сохранён 02.10.2026).

- Парсер `apps/schedule/import_service.py` читает шапку с группами, дни, пары, подгруппы; из ячейки выделяет дисциплину, аудиторию и преподавателя.
- Импорт: `python manage.py import_schedule <файл.xls>` или через страницу `/schedule/import/` (право `can_manage_schedule`).
- Каждый импорт заменяет занятия в БД; создаётся запись `ScheduleImport` с файлом, датой и счётчиками.
- Результат текущего файла: **265 занятий, 12 групп**. Для ИСТ-201 — 20 занятий в неделю, включая подгруппы (п/г 1/2).
- Студент видит расписание своей группы; сотрудник с правом управления расписанием может переключать группы.

## Ограничения демо

- SQLite и локальные файлы; для прода — PostgreSQL (`DB_ENGINE=postgres`) и S3/volume, настройки в `config/settings/prod.py`.
- Один активный роль-профиль; нет SSO, почтовых уведомлений и интеграции с ЭОС.
- Расписание обновляется вручную импортом файла, автоматической синхронизации с bgitu.ru нет.
- Стипендия рассчитывается упрощённо (базовая + ×1,8 при среднем ≥4,5), без ПГАС и социальных выплат.
- Файлы работ принимаются до 20 МБ, расширения: pdf, doc(x), zip, rar, txt, py, xlsx, png, jpg.
