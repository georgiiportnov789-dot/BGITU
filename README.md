# БГИТУ — личный кабинет

Рабочая папка проекта после реорганизации 25.10.2026. Внутри — только актуальный
портал и два архивных макета, без промежуточных копий.

| Папка | Что это | Статус |
|---|---|---|
| `ЛК-портал/` | Личный кабинет на Django 5.2 + SQLite: роли, курсы, работы, оценки, посещаемость, расписание с bgitu.ru | **рабочая версия** |
| `Макет-ЛК/` | Статический прототип ЛК: `cabinet.html`, дизайн-система, скриншоты | архив дизайна |
| `Исходный-макет/` | Исходный макет лендинга БГИТУ: `bgitu-landing.html`, описание функционала, стиль | архив |

## Запуск рабочего портала

```bash
cd "$HOME/Documents/БГИТУ/ЛК-портал"
source .venv/bin/activate
python manage.py runserver 127.0.0.1:8010
```

Открыть [http://127.0.0.1:8010/](http://127.0.0.1:8010/) — вход или регистрация.
Демо-пароль: `demo12345` (логины `student`, `teacher2`, `dean`, `developer` и др. — в
`ЛК-портал/README.md`).

## Что где искать

- Модели и БД — `ЛК-портал/apps/*/models.py`, описание схемы — `ЛК-портал/docs/DB.md`.
- Расписание — `ЛК-портал/fixtures/schedule/` + импорт в разделе «Импорт расписания».
- Скриншоты нового интерфейса — `ЛК-портал/docs/screenshots/`.
- Старый статический прототип — `Макет-ЛК/cabinet.html` (открывается без Django).
- Исходный лендинг — `Исходный-макет/bgitu-landing.html`.
